# Glosario

**Repositorio (repo)** — La carpeta del proyecto con todo su historial de cambios.

**Commit** — Una foto guardada del proyecto en un momento dado.

**Branch (rama)** — Una línea de trabajo paralela. Se prueba ahí y, si sale bien,
se junta con la principal.

**Deploy** — Publicar el sitio para que esté online.

**Markdown (.md)** — Texto plano con marcas simples de formato.

**Frontmatter** — Bloque de metadatos al principio de un `.md`, entre `---`.

**localStorage** — Memoria del navegador. Aquí guarda qué clases marcaste como
estudiadas. Es por dispositivo: no se sincroniza entre el móvil y el portátil.

**Slug** — Identificador corto de una página; aquí, el nombre del archivo sin `.md`.
